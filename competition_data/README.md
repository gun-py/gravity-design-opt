# Competition data

This directory contains public data releases from the Learn2Design 2026
evaluations. These releases provide participants with detailed feedback about
their evaluation outcomes.

## Releases

- [Round 1](round1/): results and convergence statistics for all evaluated
  Round 1 participants.
- [Round 2](round2/): aggregate results, runs, checkpoints, and shared seeds.
- [Round 3](round3/): aggregate results for 67 participants, all 670 runs,
  checkpoints, shared seeds, and the `gun-py` participant report. The downloaded
  snapshot and checksums are recorded in `round3/source.json`.

Each round directory documents its files, metric definitions, and precision.
