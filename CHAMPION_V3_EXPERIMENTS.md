# Champion V3 isolated screening

The four immutable ZIPs in `dist/` are a corrected V2 control, basin rescue, late learning-rate decay, and efficient L-BFGS polishing. The original `artifacts/baselines/local_champion.zip` and `dist/champion_v2.zip` are preserved. `dist/champion_v3_experiments.json` records archive and source hashes. Ambient `L2D_CHAMPION_FEATURES` is removed from each worker, and the four original V2 features remain enabled in every archive.

Open `notebooks/colab_champion_v3_experiments.ipynb` in a fresh Colab GPU runtime and upload `dist/l2d_champion_v3_experiment_kit.zip` (or point the first cell to it in Drive). The notebook verifies the kit, installs dfbench 0.3.3 with CUDA 12, runs archive/seed preflight and a short four-archive GPU smoke test, then executes the 12-hour stage runner. Smoke and setup time count against the wall clock. The runner writes `experiment_report.json` and `.md` after every run, plus individual logs, progress, memory traces, and diagnostics under the output directory.

Stage 1 compares control and three isolated variants on Round 3 index 8. Stage 2 compares control and up to two advancing variants on index 4. A variant must win on both development seeds with mean paired gain at least 0.02. The selected archive is locked before control and selected variant are measured on holdout index 5. The held-out pair is `24610084 / 818001683`; no local result was found for it at packaging time. A positive held-out gain recommends only further four-hour testing. If it fails, control remains the research choice, and the runner never tests the runner-up on that holdout.

Every screening job gets a full 60 scored minutes and up to 15 minutes startup; no run is shortened. Each uses one fresh process, 50 frequencies, float64, Objective microbatch one, a 16,000 MiB JAX pool limit and a sampled 19,000 MiB stop threshold. The memory guard is observational on GPUs with more than 20 GB physical VRAM. All failed or incomplete runs are reported and not retried on resume. The archive, seed, environment and selected validation variant are locked to the output directory.

Local checks: `python -m unittest discover -s tests -q`, `python tools/pack_champion_experiments.py`, and `python tools/colab_20gb_compare.py --experiment-plan analysis/champion_v3_experiment_plan.json --out /tmp/l2d_v3_preflight --dry-run`.
